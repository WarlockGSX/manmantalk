# 示例

这里放的是**流程示例**，用来说明这个 Skill 在三种典型情况下分别会怎么走。示例内容是演示用的合成片段，**不是真实家庭案例**。

| 示例 | 场景 | 走哪条路径 |
|---|---|---|
| `01-首次建档.md` | 第一次使用，问答六项 | 建档 |
| `02-口述复盘.md` | 只有回忆，没有录音或截图 | 口述咨询 |
| `03-录音分析.md` | 上传一段亲子对话录音 | 素材分析 |

> 这三个示例**不进运行时**：宿主安装时只同步 `SKILL.md`、`references/`、`scripts/`、`assets/`。它们放在包里，是为了让审核者和想改进它的人一眼看懂流程。

完整规则见 `SKILL.md` 与 `documentation/flows.md`。
