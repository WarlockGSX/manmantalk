# 示例三：上传录音（素材分析路径）

## 用户

上传一段 8 分钟的亲子对话录音。

## 处理顺序

**1. 先转写，再分析。**

优先调用当前已配置的语音识别工具（名字通常含 `transcribe`、`asr`、`speech`、`whisper`）；没有就调脚本：

```bash
python scripts/transcribe.py "<音频路径>" --out ./output
```

脚本自己选路：

| | 本地（默认） | 腾讯云（自备密钥后） |
|---|---|---|
| 录音去哪 | 留在本机 | **上传到 `asr.tencentcloudapi.com`** |
| 说话人编号 | 没有 | 有 |
| 要什么 | 一次性 `pip install faster-whisper` | 环境变量里两把密钥 |
| 费用 | 无 | 按量计费 |

想强制不上传，任何一次都可以加 `--provider local`。

**2. 先讲清要等。** 本机转写实测约 3.5–4.9 倍实时——15 分钟录音通常 3–4 分钟，1 小时约 15 分钟；腾讯云一般 1 分钟左右但要排队。**任何情况下都不说「马上好」。**

**3. 角色确认（前置校验，不占追问额度）。** 说话人编号只是**声学聚类**——它不知道谁是家长、谁是孩子；本地路径完全不产生这个字段。必须先请使用者确认哪一段是自己说的，**确认前不下任何结论**。长录音被切片时，还要按对话内容确认跨片是不是同一个人。

**4. 再进分析。** 有逐字材料 → 走**素材分析路径**，读 `references/knowledge/01-判断标准.md`，**给五维度分数与总评等级**（这是这类报告的交付物）；孩子的表现只作「家长做法是否起了作用」的效果证据。

## 两条路径的区别

| | 口述咨询 | 素材分析 |
|---|---|---|
| 输入 | 只有回忆 | 录音转写 / 截图原文 |
| 读 `references/knowledge/01-判断标准.md` | **不读** | 读 |
| 维度分与总评等级 | 不给 | **给** |
| 判断依据 | 事件顺序与反复出现的模式 | 逐句位置（谁在哪一句转折） |

## 隐私

录音里是孩子的声音，属敏感个人信息。启用云端前须确认已取得监护人同意；本地路径不上传，是最强的隐私保护。密钥由使用者自己申请和填写，**Skill 不代注册账号、不写任何配置**。
