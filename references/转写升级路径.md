# 转写升级路径

> **这份是可选配置。** 默认路径（脚本内置的本地转写）已经能干活，不读它也能用。
> 只有当你想要说话人编号、想用云端算力、或想换成别的厂商时才需要往下看。

---

## 一、默认路径：本机离线（什么都不用配）

```bash
python scripts/transcribe.py "<音频路径>" --out ./output
```

| | 说明 |
|---|---|
| 在哪跑 | 本机，全程离线 |
| 要什么 | 一次性 `pip install faster-whisper`；首次运行下载模型（small 约 500MB，国内默认走 hf-mirror） |
| 上传吗 | **不上传**。录音留在本机 |
| 花钱吗 | 不花。不需要账号或密钥 |
| 缺点 | **没有说话人编号**——角色由 AI 按语言特征推断，再请你确认 |
| 速度 | 实测约 3.5–4.9 倍实时：15 分钟录音 3–4 分钟，1 小时录音约 15 分钟 |

**模型自动下载失败时**，先手工把模型目录下到本机，再用 `--model-dir <目录>` 加载；脚本报错时会把完整命令一起给出来。

**产出两个文件**，都落在 `--out` 指定的目录：

- `<文件名>.jsonl`：结构化逐字稿，每段带起止时间、文字，以及**本机从音频算出的音量与语速**；本地路径另带模型给出的把握度字段（`avg_logprob` / `no_speech_prob` / `compression_ratio` / `temperature`，原始值，不做换算）。
- `<文件名>.md`：同一份内容，给人读。

这些字段**只用来如实描述这一段，不要拿它们推断心理状态或性格**——「语速快」不等于孩子焦虑，「音量低」不等于在压抑。字段缺了就如实说缺，不要补，也不要换个说法把它圆上。

**它是默认，不是过渡方案。** 不觉得“没有说话人编号”碍事，就不用往下看。

## 二、内置的云端路径：腾讯云（已经做进脚本了）

脚本里已经接好腾讯云录音文件识别。**它不会自动启用**，只有环境变量里同时存在两把钥匙才走云端。

### 2.1 怎么开

设两个环境变量即可，**不需要改任何代码**：

| 变量 | 说明 |
|---|---|
| `TENCENTCLOUD_SECRET_ID` | 腾讯云 SecretId |
| `TENCENTCLOUD_SECRET_KEY` | 腾讯云 SecretKey |
| `TENCENTCLOUD_REGION` | 可选，默认 `ap-guangzhou` |

Windows（新开的终端才生效）：

```
setx TENCENTCLOUD_SECRET_ID "你的SecretId"
setx TENCENTCLOUD_SECRET_KEY "你的SecretKey"
```

macOS / Linux：写进 `~/.zshrc` 或 `~/.bashrc`：

```
export TENCENTCLOUD_SECRET_ID="你的SecretId"
export TENCENTCLOUD_SECRET_KEY="你的SecretKey"
```

> **钥匙只放环境变量，绝不写进这个 Skill 的目录。** Skill 会被复制和分享，写进去等于把账号送人。
> 另外**不要用主账号密钥**——去建一个子账号，只授权语音识别。密钥泄露的代价差一个量级。

### 2.2 开了之后，变的是什么

| | 本地 | 腾讯云 |
|---|---|---|
| 录音去哪 | 留在本机 | **上传到腾讯云处理** |
| 说话人编号 | 没有 | **有**（每段一个编号） |
| 把握度字段 | 有（`avg_logprob` / `no_speech_prob` / `compression_ratio` / `temperature`） | **没有**——接口不返回，字段留空 |
| 音量与语速 | 有（本机从音频算） | **有**（同样本机算，不受影响） |
| 费用 | 无 | 按量计费 |
| 速度 | 3.5–4.9 倍实时 | 一般 1 分钟上下，另需排队 |

**上传这一条要你自己确认能接受。** 录音里是孩子的声音，属敏感个人信息。

### 2.3 单次 5MB 限制，和“跨片编号不可比”

腾讯云直传（`SourceType=1`）**单次音频上限 5MB**（base64 之后，实际可用约 3.75MB 原始数据）。
脚本的处理方式：

1. 先用 opus 从高码率往下**实测编码**，取第一个能整段塞进限额的码率；
2. 整段放不下，才用下限码率切片（每片约 10–18 分钟），逐片提交。

所以：

- **10 分钟以内的录音基本都是单次提交** → 说话人编号全局一致；
- **超过之后可能被切片** → 逐字稿里会标出切片位置，但**第 2 段的「说话人0」未必和第 1 段是同一个人**。每段是独立做的说话人分离。分析前必须按对话内容确认跨片对应关系。

想彻底避免切片，只有一条路：把文件放到一个可公网访问的 URL 上，改用 `SourceType=0`（此时上限放宽到 1GB / 12 小时）。那就绕不开对象存储了——**这一条不在内置路径里**，要做的话得自己搭。

### 2.4 怎么关掉 / 只对某一次用云端

```bash
python scripts/transcribe.py "<音频路径>" --provider local     # 强制本地，绝不上传
python scripts/transcribe.py "<音频路径>" --provider tencent   # 强制云端，没密钥直接报错
```

`--provider auto` 是默认值：有密钥走云端，没密钥走本地。**只要设了钥匙就是全局生效的**——哪天只想本地跑一次，就用 `--provider local`，别把钥匙删了又加。

### 2.5 费用与地域

- **价格这里不给。** 搜到的报价口径不一，请以腾讯云官网语音识别定价页为准。
- 地域默认 `ap-guangzhou`。换地域用 `--tencent-region` 或设 `TENCENTCLOUD_REGION`。
- 引擎默认 `16k_zh`（中文）。脚本按 `--lang` 映射：`zh` / `en` / `yue`。

### 2.6 第一次跑没成功，看这里

加 `--dump-raw`，脚本会把云端每次调用的**原始响应**存到 `<out>/<文件名>.raw.json`：

```bash
python scripts/transcribe.py "<音频路径>" --out ./output --dump-raw
```

常见原因：

| 现象 | 原因 |
|---|---|
| `AuthFailure.SignatureFailure` | 系统时间不准（签名依赖时间戳，偏差超过 5 分钟必失败） |
| `AuthFailure.SecretIdNotFound` | 密钥填错，或用了非云 API 密钥类型 |
| `FailedOperation.*` | 音频格式/采样率不被接受，试 `--codec mp3` |
| 提示“读不出音频” | 缺 PyAV：`pip install av`。原文件又超过 5MB 时无法提交 |

## 三、什么时候值得换别的方案

| 你的情况 | 该往哪走 |
|---|---|
| 就想要说话人编号，英文/中文对话 | **第二节的腾讯云已经够用** |
| 想要说话人直接是“爸爸/妈妈”而不是编号 | 看 4.1（只有 OpenAI 那个模型支持声纹命名） |
| 录音超过 1 小时、又不想切片 | 4.2（要对象存储） |
| 已有自己的转写服务，或想装社区现成的 | 第五节（MCP） |
| 只在意隐私，一点都不能上传 | 留在第一节，不要往下看 |

## 四、选项 A：其它云端语音识别

**脚本没内置这些。** 要用得自己写调用、或让 AI 按本文件的字段说明改造 `scripts/transcribe.py`。
下面都是**已核对过官方文档**的结论，不是道听途说。

### 4.1 OpenAI `gpt-4o-transcribe-diarize`

唯一一个“一次调用同时给出文字 + 说话人 + 时间戳、且**直接传文件**”的现成选择。

- 端点同 `/v1/audio/transcriptions`，`multipart` 直传
- `response_format=diarized_json`，`chunking_strategy=auto`（超过 30 秒的录音要带上）
- 返回 `segments[]`，每段有 `speaker` / `start` / `end` / `text`
- 还支持 `known_speaker_names` + `known_speaker_references`：提交一段某人 10–30 秒的干净语音，模型会把该说话人直接标成你给的名字，**不用再猜角色**

**代价**：需要能访问 OpenAI API（国内直连常不通）；文件上限 25MB 量级（以官方文档为准）。
**声纹是敏感生物识别信息**，孩子的声纹更敏感——要用就做成显式开启、默认关闭，样本文件放在 Skill 目录外。

### 4.2 阿里云百炼（DashScope）

- **能分离**的是 `fun-asr` / Paraformer 系列 / `Qwen-Audio-3.0-ASR-Flash-Filetrans`，
  在请求里设 `diarization_enabled=true`，返回每句带 `speaker_id`。
- **但录音文件识别走的是 `file_urls`（公网 URL），不接受直接传本地文件** → 必须配 OSS 建桶。
- ⚠️ **`Qwen3-ASR-Flash` 明确不支持说话人分离**，且限 5 分钟音频。网上有些文章把它当“能分离”来推荐，是错的。
- 官方提示：启用说话人分离时建议音频不超过 2 小时，且仅支持单声道。

### 4.3 一句话对照

| 方案 | 直传文件 | 说话人 | 主要门槛 |
|---|---|---|---|
| 腾讯云（**已内置**） | ✅ 但 ≤5MB | ✅ 编号 | 需要密钥；长录音会切片 |
| OpenAI `gpt-4o-transcribe-diarize` | ✅ | ✅ **可命名** | 需要能访问 OpenAI |
| 阿里云百炼 | ❌ 要公网 URL | ✅ 编号 | 要对象存储 |
| 本地 + pyannote | — 不出本机 | ✅ 编号 | 要装 torch + 两个 gated 模型 + HF token |

> 本地 + pyannote（`pyannote/speaker-diarization-community-1`）是“不想上云但要分离”的正解，
> 它是开源的 SOTA。代价是不轻：要装 PyTorch 约 2GB 依赖、要接受 HuggingFace 上两个模型的条款、
> 要自备 HF token，还要 ffmpeg。**而且既然本地都装了 pyannote，本地 whisper 其实也几乎白搭。**

## 五、选项 B：转写 MCP

MCP 是让 AI 直接调用外部工具的协议。接好之后本 Skill 处理录音时会**优先调它**，不再起脚本——你不需要改 Skill 里的任何东西。

### ⚠️ 三件必须先说清的事

1. **Skill 无法自带 MCP 并让它自动生效。** 技能包只能带 `SKILL.md`、`references/`、`scripts/`、`assets/` 这类静态资源，**没有声明或注册 MCP 服务器的字段**。所以必须由**你自己**配。
2. **MCP 是全局的，不是这个 Skill 私有的。** 配好之后你的所有对话都能看到这个工具。
3. **写完配置还要手动点一次「信任」才会生效。** 这是安全设计，没有旁路。

### 配置位置

`~/.workbuddy/mcp.json`（**注意不是** `.mcp.json`，带点的是另一个文件，改它没用）。
Windows 下即 `C:\Users\<用户名>\.workbuddy\mcp.json`。

### 现成的实现（**搜索结果，未逐一实测**）

| 实现 | 特点 | 注意 |
|---|---|---|
| `whisper-transcribe-mcp`（ZahiriNatZuke） | faster-whisper 本地 / OpenAI Whisper 云端，**有 `OPENAI_API_KEY` 就自动走云端**，失败回落本地 | 需要 uv 或 pip |
| `@clawbow/mcp-whisper` | OpenAI / whisper-cli / whisper.cpp 三后端，`WHISPER_PROVIDER=auto` | npm 包 |
| `ebmarquez/audio-transcription-mcp` | faster-whisper + **pyannote 自动说话人分离** | 需要 HuggingFace 账号与 token，并接受模型条款 |
| `Cloud-ASR-MCP`（danielrosehill） | 用多模态大模型直接吃音频，可带提示词做清洗 | 作者自标 **WIP**，谨慎 |

> **这些是从公开目录搜到的社区实现，没有逐一实测过。** 用之前自己确认仓库还在维护、依赖装得上、许可证能接受。
> **不要用来源不明的中转/聚合站**——那等于把孩子的录音多交给一个第三方。

## 六、无论走哪条路，都要守的合规底线（不是可选）

录音里有孩子的声音，属敏感个人信息。

| 事项 | 要求 |
|---|---|
| **监护人同意** | 录制、以及上传给第三方处理，**都需取得监护人明示同意**，不能用默认勾选或事后告知代替 |
| **优先本地** | 能本地就本地——不上传是最强的隐私保护。这也是默认路径选本地的原因 |
| **用完就删** | 云端方案必须设自动清理；本地处理完也建议提示使用者删掉原音频 |
| **报告脱敏** | 报告正文不出现真实姓名、学校、班级、住址 |
| **密钥隔离** | 密钥只放环境变量，**绝不写进本 Skill 目录**——Skill 会被分享和复用，写进去等于送账号 |
| **不用主账号密钥** | 建子账号，只授权语音识别 |

> 使用者是老师或非监护人亲属时，上传前要提示先获得监护人的同意。
