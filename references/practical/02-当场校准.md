# 当场校准

## 定位

这份文件管一件事：冲突正在发生的那几十秒，你做什么。它对应的是「话已经说出口、孩子已经炸了或已经不说话了」这种时刻，不是事后，也不是开场。

三个入口对应三种当下：孩子情绪上来了（这一份第一节）、你自己快失控了（第二节）、双方都停不下来（第三节）。第四、五节给一张可以现场照着看的对照表。

它不管三件事：不管这场冲突该不该发生（那是你前面时机的事，在 `references/practical/01-开口与演练.md`）、不管事后怎么补（那是 `references/practical/03-事后修复.md`）、不管行为边界本身怎么定（那是 `references/practical/04-日常冲突与规则.md`）。

一个前提：当场的目标只有一个——把这一轮停下来，不让它继续升级。 不是讲通道理，不是分出对错，不是让他认错。这些在当场都做不到，硬做只会把这一段拉长。道理留到事后。

## 一、孩子情绪上来了，先做减法

孩子进入情绪唤起状态后，有一段时间听不进道理——这不是态度，是当下的生理状态：心跳快、呼吸浅、脸发热、手抖、声音变大，此时理解语言、组织回应、预想后果的能力会暂时下降［1］。所以这一节的全部动作是「先做减法」。

要做的三件事，按顺序：

- 降你的音量，不是升。 他声音越大，你越要小。音量是现场最容易传染的东西，两个都往上走就收不住了。
- 退半步，把身体松开。 不再正对着他、不再往前压、不再用手指。身体的压迫感是升级最快的一根线。
- 说一句最短的话给出口。 短到十个字以内，内容只有一个意思：现在可以停。比如：

> “我们现在都停一下。”

不要做的四件事，每一件都在把这一轮拉长：

- 不要当场讲道理。 「我这么做是为了你好」「你想想你自己有没有问题」——现在是听不进去的时段，说了也是白说，还会被当成新一轮攻击。
- 不要追问原因。 「你到底为什么发这么大火」在他情绪高点上是逼他再组织语言，等于加码。
- 不要翻旧账。 「上次也是这样」「你每次都这样」——把一件事变成一类事，他会为「我是不是这样的人」辩护，原话题消失。
- 不要用离开作惩罚。 「我不管你了」「你自己待着吧」——这是在关系层面加码，这类信号会同时激活「想靠近」和「想逃开」两种反应。

把「先处理情绪、再处理事情」排在这个顺序上，是情绪教练做法里最基本的判断：孩子情绪被激起时，先接住、再立界限，顺序反了就两头都落空［B1］。把「他现在是下层脑在接管、上层脑还接不上」讲给家长听，是帮助父母忍住「当场讲道理」这一冲动的一个常见解释角度［B2］。

### 什么算停下来了

不用等他不气，等到三个信号里出现两个，就算这一轮可以收：

- 声音下来了，或从喊变成说
- 呼吸和肩膀松下来，不再绷着
- 内容从「攻击你」变成「说他的事」——开始讲发生了什么，而不是指责你

出现这些之前，你只做上面那三件事，不推进话题。

## 二、你自己快失控了，先离开一会儿

这一条排在孩子之前讲，因为它更常是升级的真正起点。长期紧绷、睡不好、压力没有出口的时候，触发线会往下移——同一件小事，平时不当事，那个阶段就爆发，而这与这件小事本身关联不大［2］。

识别你快要失控的信号，比识别孩子的更重要。常见的有：太阳穴发紧、下巴咬住、声音开始发颤或拔高、脑子里出现「我今天非得治治他」这类句子、想伸手或想摔东西。出现任何一个，先走下面这一步：

- 停嘴。 不要再说完这一句，哪怕说到一半。把话咽回去比说完它更管用。
- 离开现场，但要交代。 不是甩门走人，是给一句清楚的：

> “我现在有点上来了，我需要出去待一会儿。十分钟。我回来的时候还是在的。”

- 做一件打断身体的事。 洗把脸、喝口凉水、在楼下走两圈、数自己的呼吸到二十。要点是把注意力从「那句话」移到「身体现在怎样」。
- 给自己一个时间点。 十分钟、半小时，说清楚几点回来。没有时间点的离开，孩子读到的就是「他不要我了」。

有一件事不要做：不要在离开前留下最后一句评价。 「你自己好好想想」「等我想通了再说」——这一句会把「我去冷静」变回「我在罚你」。离开本身要干净。

你在当场怎么处理自己的情绪，本身会被孩子学去——长辈的情绪调节方式与孩子的情绪调节方式之间存在纵向关联［3］。所以第二节讲的「先处理自己」，既是让这一轮停下来，也是在给他做一个可看的样本。

如果发现自己经常在同一个点上失控，那已经不是当场能解决的事——它指向你自己的状态，按 `references/practical/09-长辈自我照顾.md` 处理。

## 三、两个人都停不下来，先中断现场

有时候两个人都在高点。这时不讲谁对谁错，先把物理现场拆开。

- 分开空间。 各回一个房间，或一个人出门。不是冷战，是给两个身体都降下来。
- 降一件事的要求。 当下不要要求任何一方「先道歉」「先说清楚」。矛盾的是关系，不是这句话。
- 给一个明确的再谈时间。 不要让冲突悬在半空——「今晚都先睡，明天吃完晚饭我们再说这件事」。有时间的悬置是休息，没时间的悬置是冷战。
- 如果是肢体冲突，先保人的安全。 把两个人分开是第一动作，比对错重要；受伤先处理伤。触及 `references/knowledge/08-危机识别与求助渠道.md` 的红线内容，走那一份，不走本份。

## 四、现场对照表

这张表是这一份的核心，用来的就是「看见信号→这一秒做什么」。左边是当下能观察到的，中间是你可能的冲动，右边是当场更该做的动作。

| 你看到 | 通常的冲动 | 这一秒改做 |
| --- | --- | --- |
| 孩子声音拔高、拍桌子 | 比他更大声压回去 | 降到比他小，说一句「我们停一下」 |
| 孩子摔门、走进房间 | 追上去把门拍开 | 让他关，隔一段时间再敲门，说「我在门外，你想说的时候我听着」 |
| 孩子哭 | 说「这有什么好哭的」 | 不说话，坐近一点，递纸巾或手边的东西 |
| 孩子说狠话（「我恨你」） | 用更狠的话回敬 | 接住话里的情绪，不接字面：「你现在特别气我，我知道。」 |
| 孩子翻旧账 | 逐条反驳 | 「你说的那个也是真的，我们一件一件来，先说你刚才这件。」 |
| 你自己声音开始颤 | 说完这最后一句 | 停嘴，按第二节离开并交代 |
| 你手已经抬起来 | 打下去 | 立刻把手放下，转身走出房间，先处理你的动作 |
| 孩子沉默到底 | 一直问到他说 | 停下，给一句出口：「不想说就先不说，我在这。」 |
| 两个人都红了眼 | 逼出一句道歉 | 分开空间，定一个明天再谈的时间 |
| 孩子开始人身攻击 | 用「你就是……」定性他 | 不接定性，把话收回到这件事上：「你气我，这件事我们等会儿说。」 |

对照表不是台词本。用法是挑右边那一栏里最贴近的一句，照你自己的话说出来——同一个动作，用你家的词，才不是背来的。

## 五、当场结束之后

这一轮停下，不等于事情结束。分两个方向：

- **要补的**：等双方都平复了，回头把这件事谈一次——怎么起的、下一次这种时候怎么办。这一次要放在事后，不在当下。走 `references/practical/03-事后修复.md`。
- **要看的**：把这次冲突按 `references/knowledge/01-判断标准.md` 过一遍，看卡点落在哪。是你先失控、是孩子确实有件事没出口、还是这次纯粹是累积到顶了。三种卡点的下回处理不同。

有一件事不要做：不要把上一次冲突的「现场」攒到下一次。 每次都在「上次你还没给我交代」上开场，关系就一直停在那一场没结束的架里。

## 六、这份文件的限制

- 不给通用话术。对照表右边是动作方向，不是句子；同一句在不同家里、不同年龄要重搭。
- 不保证当场能解决。当场能做的只是「不升级」，真正的解决在事后。
- 不代替对你自己状态的长期管理。如果你发现每次冲突都由你的失控触发，问题不在「当场怎么接」，在你最近的状态，走 `references/practical/09-长辈自我照顾.md`。
- 不适用于危机情境。出现 `references/knowledge/08-危机识别与求助渠道.md` 里的红线信号时，不走这一份，直接给渠道。
- 不同学段要改做法。同一个「摔门」在小学和高中含义不同，按学段判断的判据在 `references/knowledge/02-学段差异.md`。
- 涉及行为边界本身（什么不能做、边界怎么定），那是 `references/practical/04-日常冲突与规则.md` 的事，本份只管冲突当下这一段。

## 依据说明

本份属做法层，整理的是「冲突当下这几秒做什么」的操作方法，来源是沟通与家庭教育的通行做法，其中一部分是对「当场失控」场景的整理，不是某项研究。

正文中三条结论有文献支撑：情绪唤起时理解与组织语言的能力暂时下降［1］；长期压力会压低触发门槛，长辈当天一点就着与事件本身关联不大［2］；长辈的情绪调节方式与孩子的情绪调节方式之间存在纵向关联［3］。三篇的出处见本份 `## 参考文献`。

本份在排「先接情绪、后谈事」这个顺序时，采用了情绪教练做法里通行的处理次序［B1］；把孩子的失控解释成大脑上下层暂时接不上，借用了面向家长的整合框架的说法［B2］。这两处借的是解释口径和顺序，不是实证结论，本份不据此声称任一说法已被证实。

第四节的对照表，是把「父母十二型破坏性表达」反过来用——十二型讲的是「不该怎么做」（如批评指责、否定打断、命令控制、情感勒索），本份把每条反例对应到一个可做的动作，属整理者根据素材方向自建的对照，不对应单篇研究。正面的当场操作在素材里几乎没有，这张表是按通用做法补的。

做法层中涉及「离开现场要交代、要给时间点」这类动作，属使用分级 B（要看条件）：给的时候一并说明它什么时候不适合用（如孩子正处在安全风险中时不能离开），以及做不到会付出什么（不交代的离开会被读成抛弃）。
