# 判断标准

这份文件管两件事：什么算一次好的沟通，以及等级怎么来。它不管流程——流程在 `SKILL.md` 的《每次分析》一节；它也不管每种场景读哪份材料——那在同一份的《按需加载》里。

**适用范围：有逐字材料的对话分析。** 录音转写，或聊天截图、导出记录的可见原文。这里的维度、卡点判定和等级都建立在「谁说了什么、下一句接在哪一句后面」上（第四节写明「判定的关键在位置，不在数量」）。只有使用者的口述和回忆、拿不到逐句材料时，**本份整份不适用**——那类情形按 `SKILL.md` 的《两条分析路径》处理，给描述性判断，不给维度分、不给卡点判定、不给等级。

分析一段有逐字材料的对话时，先按 `SKILL.md` 的《每次分析》把事实摆清楚，到要给判断和等级时读这份文件。这里的判据是唯一出处，不要在别处复述。

---

## 一、两条底线

第一条：孩子侧的表现是效果证据，不是评分对象。

孩子说得少、变沉默、开始敷衍，说明的是长辈的上一句话产生了什么效果，不是孩子表现得不好。所以本 Skill 不给未成年人打分、不做测评、不贴标签。孩子侧只做观察记录，用途是印证长辈的做法是否起了作用。

这条同时意味着：一份“孩子全程沉默”的对话，不是孩子得了低分，而是长辈这一路没有说话让孩子愿意接。

第二条：有原话才引原句。

录音转写、聊天记录有原话，可以指出“哪一句转折”，可以引原句作证。原话是这套判据的入场券：拿不到原话（只有使用者的口述和回忆）时，本份整份不适用，按 `SKILL.md` 的《两条分析路径》处理——不复述没被讲到的对话，不编造引用。

转写置信度低的片段单独标出，不基于它下判断。

---

## 二、长辈的五个维度

五个维度都从长辈说了什么、做了什么来判断，不从“他是个什么样的人”来判断。每个维度给 0–5 分，保留一位小数。

### 倾听与理解

看长辈的下一句是不是接着孩子的话说的。

好的样子：孩子说完，长辈的回应里带着孩子刚说的词或意思——复述、确认、往下问。孩子说得含糊时先问，不先给答案。

待改进的样子：孩子还在说，长辈的话已经接上去了；或者把孩子的感受当成事实来反驳。比如孩子说“今天不想去，好热”，回“热什么热，车上都有空调”——这句话处理的是“热不热”这个事实，孩子想说的是“我不想去”，那个感受没有被接住。

### 开放心态

看孩子说出不同意见时，长辈的下一句往哪走。

好的样子：不否定，也不追问对错，而是往下问“你是怎么想的”。允许孩子说到一半改主意。

待改进的样子：替孩子下结论——“你就是不想去”“你就是懒”；把孩子的“不”当成态度问题而不是信息，比如“怎么又不想去”。

### 支持与鼓励

看肯定落在哪里。

好的样子：肯定落在过程上——“你刚才自己改了两遍”，而不是“你真聪明”［1］。孩子卡住时先给方法或陪着，不先给评价。

待改进的样子：拿别人比较；只在结果好时才回应。

### 真诚交流

看长辈有没有把自己放进去。

好的样子：说自己的感受和难处，不只是提要求；有承认自己没做好的地方。

待改进的样子：说教句式密集（“你应该”“你不能”“我跟你说过多少遍”）；反问句当批评用（“你自己说是不是”）。

### 情感连接

看情绪变化发生的那一下，长辈做了什么。

好的样子：孩子的情绪突然起来时，长辈停一下先回应那个情绪；对话里有放松的时刻——开玩笑、一起回忆。

待改进的样子：孩子情绪上来，长辈的情绪跟着上去；冲突以孩子让步结束，而不是孩子被说服。

## 三、孩子侧的效果指标

不给分，只记录。用途是判断长辈的做法起没起作用。

- **表达长度**：开头几轮和后半段比，是在变长还是变短。断崖式变短通常紧跟在某一句之后，那一句要单独看。
- **主动发起**：不问也自己说的有几次。
- **被回应之后的下一条**：孩子说了感受、请求或不同意见之后，下一条是继续说，是变短，还是不说了。
- **收尾**：这段对话是谁结束的、以什么方式结束的。
- **放弃表达的信号**：“随便吧”“都行”“你说什么就是什么”——这类句子出现的位置比其他任何指标都值得看。

孩子侧不出现“沟通意愿弱”“不够主动”这类判断句，那是给孩子定性。

## 四、卡点

卡点是对这段沟通关系有负面影响的具体行为，不是能力不足，也不是知识欠缺。

这两件事在报告里必须分开：

- 不愿意说 → 可能是卡点
- 还在学、还不会 → 不是卡点

### 常见类型

否定式说教 / 无视孩子的表达 / 话题终结 / 抑制表达 / 不文明用语 / 音量或语气失控 / 打断 / 否定孩子的感受 / 命令式表达 / 转移话题 / 打压式比较 / 忽略孩子的情绪 / 否定式打断。

### 不算卡点

孩子思考时的停顿、问答里的简短确认（“对”“嗯”）、对话自然收尾（“好的”“知道了”）、孩子因为知识或能力不够答不上来。

### 卡点可以为零

不是每次都非得找出卡点。一次沟通里没有任何对关系造成负面影响的具体行为，是正常且值得说出来的结果。

卡点为零时，报告要明确写出来，不能含糊带过、也不能硬凑一个。这是这次沟通的亮点，和“做得好的地方”一起给足证据。

卡点和等级各算各的。卡点为零只说明这次没有出现伤人的具体行为，不代表整体评价一定高——等级仍由五个维度算。两者同时出现时如实都写，例如“这段对话基本没聊起来（孩子多数时候没接话），但你全程没有否定或打断他”。

### 判定的关键在位置，不在数量

长辈说了多少次祈使句，不如这些句子落在哪里重要。判断某一句是不是卡点，看它后面紧跟着发生了什么——把这句话、孩子在这句之前的一条、之后的一条，三条放在一起看。孩子从积极参与突然变成沉默或敷衍，且之后没有恢复主动表达，这一句才算卡点。

## 五、等级

### 总评：五档质量 + E · 安全红线

| 等级 | 大致长什么样 |
|---|---|
| S | 双方都在说，孩子多次主动表达；长辈至少三次准确地接住了孩子的情绪或想法；没有影响走向的卡点 |
| A | 整体顺畅，有明确可指出的亮点，也有一到两个位置可以改 |
| B | 聊完了，但长辈的话以要求和评判为主，孩子多数时候是被动回答 |
| C | 基本没聊起来，或者过程中出现了明显的损伤——孩子沉默、冲突升级、以孩子让步收场 |
| D | 多数方面同时明显不足——长辈基本没接住孩子，孩子几乎没有表达空间，或中途退出，这次沟通没有真正发生 |

S/A/B/C/D 是沟通质量的五档，都由分数算出（见下）。上表用来判断每个维度该给几分，也用来检查算出来的等级合不合理；两边对不上时，回头看维度分是不是给偏了，不以描述为准。

E 不是质量档，是安全红线的代号，不由分数触发。录音或记录里出现红线内容（自伤、被欺凌、被不当触碰、动手致伤、持续“活着没意思”）时记为 E，走 `references/knowledge/08-危机识别与求助渠道.md`，暂停常规报告——这一轮不给等级、不给沟通评价，先给求助渠道。

E 和 S–D 不在一条轴上，不参与排序、不和它们比高低。E 回答的是“安不安全”，五档回答的是“聊得好不好”；两者可以同时出现（聊得挺好但触了红线），也可以单独出现（聊得不好但一切平安）。所以不要写成“比 D 更差”，也不要把 E 接在 D 后面当第六档。

### 分维度打分

分维度给 0–5 分，保留一位小数。总评只给等级，不向使用者展示总分。

### 从维度分到总评

第一步 · 折算总分：五个维度的分数相加（满分 25），乘以 4，得到一个 0–100 的分数。

因为每个维度是一位小数，五个数之和的步长是 0.1，折算后步长是 0.4——95、85、75 这类整数取不到（最接近的是 94.8 / 95.2；60 恰好取得到）。所以折算完四舍五入取整，再切档，避免 94.8 落在哪一档这种擦边问题。

第二步 · 按总分切档

| 等级 | 总分 |
|---|---|
| S | ≥ 95 |
| A | 85 – 94 |
| B | 75 – 84 |
| C | 60 – 74 |
| D | < 60 |

第三步 · 两条封顶调整。只做封顶，不做加分。

1. 孩子侧封顶：孩子在对话后半段完全停止主动表达，或出现放弃表达的信号，总评最高到 B。理由：长辈的做法没有让孩子愿意继续说下去，这一点比单个维度分更能说明这次沟通的实际效果。
2. 偏题封顶：使用者说明了这次本来想聊什么、而对话实际没往那里走时，总评最高到 A。偏题的责任在长辈，不影响孩子侧的任何记录。

两条封顶可以叠加，取更严的那条。

### 依据充分度

本份只用于有逐字材料的分析：只有使用者的口述和回忆、没有原话时，不给维度分、不给等级。即使有材料，找不到足够证据支持某个维度的分数时，宁可标“证据不足”，不给一个看起来精确的数字；材料本身不完整（缺了一段、转写置信度低）时照此处理，并在等级旁注明判断依据有限。

## 六、怎么说

判据决定说什么，这一节决定怎么说。原则第 2 段要求方法必须是可执行的句子，这一节是那条要求的落地。

- 用第二人称直接对话，像朋友之间说话，不用专家口吻。
- 每个维度上，先写已经做得好的具体表现，再写可以调整的方向，两半都不能省。
- 指出方向时给可照说的句子，不给“你应该多共情”这类原则。给句子时带上说的时机，并说明孩子可能有哪几种反应、分别怎么接。
- 引导语要换着用：“如果先……再……，也许会……”“不妨试着……”“下次可以……”。同一页里不要连续用同一个。
- 不要用“但”“不过”“然而”把肯定和建议硬切开。
- 复述孩子的话可以，不给孩子下判断句。
- 等级偏低时，不用“差”“不合格”“很糟糕”这类词评价这一次，改成陈述发生了什么——比如这次多数时候是一方在说、另一方没接上，或这次没有真正聊起来——接着先说清是哪几处让它停在原地。低档位更需要指路，不是更需要判决。
- 引用育儿体系时，区分有实证支持的方法、成熟框架和流行说法。除非使用者要求，不展开理论史和课程版本史。

## 七、引用的体系

本文件判断时可参照的体系：依恋理论、非暴力沟通、正面管教、人本主义（罗杰斯）、个体心理学（阿德勒）、最近发展区（维果茨基）、儿童心理学（德雷克斯）、马斯洛需求层次。

用的时候遵循两条：说人话——引用是为了把原因说清楚，不是为了让报告显得专业；不分年龄乱用——具体说法先过 `references/knowledge/02-学段差异.md`。

**判断要不要留心年龄，有两处最容易读错**：一是**同一个表现的含义随学段变**（同一个「顶嘴」，小学高年级是自主需求刚萌芽，高中可能是他给你的入口）；二是**情绪的表达面孔在初中换过一次**——同样的低落，这个阶段更常显示为易怒、一点就着。同一段对话里长辈的「没接住」，在初中段要连着这个背景看，别直接把孩子的火气读成他的性格问题。判据在 `references/knowledge/02-学段差异.md`；**同一个教养动作在不同学段的性质也不一样**（同一句「别忘了写作业」，在小学是提醒，在初中容易被读成不信任），长辈这边该怎么随之调整见 `references/knowledge/04-家庭系统与教养方式.md` 第七节。

## 依据说明

本份是操作规范，不是知识整理——五个维度、卡点清单、五档等级和折算规则，都是本 Skill 自己定的判据。它的作用是统一口径，让同一段对话在不同时候得到同一套判断，不是给这套判断挂靠学术出处。

其中「肯定落在过程上而不是结果或天赋上」这一条，来自一项对五年级学生的实验研究：被夸聪明的孩子在被夸努力的孩子的对照下，遇到挫折后更少坚持、更在意表现目标、更容易把失败归因于能力不足［1］。这条只用来支持第二节「支持与鼓励」这一维度的方向，其余判据仍为整理者的设计。

设定其余判据时参照的框架（第七节列出的八个体系）已列出，采用其含义，不逐条溯源。其中两个体系的原始出处是书：人本主义强调真诚、无条件积极关注与共情，是罗杰斯提出的助益性关系三要素［B1］；个体心理学关于「行为以目的为导向、不当行为是丧失信心的表现」的基本主张，出自阿德勒［B2］。

整体属证据分级 D（本套材料自定的判据与规则）：判据本身是整理者的设计，用来统一口径；不构成对孩子或长辈的测评，也不用于个案定性。红线（E）的识别与求助渠道单列在 `references/knowledge/08-危机识别与求助渠道.md`，不进入这套评分。
