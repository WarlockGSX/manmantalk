# 导读与使用分级

## 定位

参考分两层。读之前先分清自己在读哪一层，两层的写法和用法都不一样。

| | `references/knowledge/` 机制层 | `references/practical/` 做法层 |
|---|---|---|
| 回答什么 | 这是怎么回事、凭什么这么判断 | 下一步说什么、做什么 |
| 内容从哪来 | 外部依据：研究、法条、发展规律 | 我们总结的做法，以及它的代价 |
| 自带的分级 | 证据分级（下面第二节） | 使用分级（下面第三节） |
| 最怕被怎么误用 | 被当成定论——把依恋类型读成对孩子的判决书 | 被机械照搬——把给过的说法当模板到处套 |

一句判定：这份材料是在回答「事情是怎样的」，还是在回答「你该做什么」？ 前者放机制层，后者放做法层。

同一个主题两层都要时，机制抽到机制层、动作留在做法层。所以“情绪爆发”和“关系状态”会共读同一份机制文件，不必各写一套。

根目录下另有两份不属上述两层：本份（目录与规则），以及 `references/转写升级路径.md`。后者是转写的工程配置，只在需要云端转写或自动说话人分离时才读，不承载沟通知识，也不参与证据分级。

## 一、证据分级（机制层用）

按来源强弱标注，说话时用对应语气，不把弱的说成强的。

- **A**：系统综述、元分析、大样本纵向研究、现行法律与权威指南。可表述为“证据较一致”“现行规定为”。
- **B**：设计良好的单项研究、多个团队反复出现的发展规律。可表述为“有研究提示”“可能如此，仍需结合情境”。
- **C**：临床分类、流行框架、经验说法。可表述为“一种常见说法”“可作为参照”。
- **D**：本套材料自定的判据与规则，没有外部来源可挂。可表述为“本套材料的做法是”。它的用途是统一口径，不是给内容排等级；也不能被读成“比 C 更弱”或“没有依据”。

临床口径单独处理：涉及诊断分类的内容（患者、住院、用药、病程），只用来判断“要不要建议求助”，不进报告的判断、不给孩子下结论或贴标签。这是《安全边界》里「不诊断」在这一层的落点。

## 二、使用分级（做法层用）

给做法时必须同时交代它的条件与代价，不能只给动作。

- **A 可直接给**：说事实不说判断、给选择不给命令、先接情绪再谈事、承认自己的部分、修复而不追责。可直接当建议框架，也可直接给一句贴合使用者用词的首选说法。
- **B 要看条件**：涉及“什么时候谈、说几句、对方不接受怎么办”的，给的时候一并说明**适用条件、预期效果、暴露的风险与代价**。
- **C 不给**：撤回关注、制造愧疚、反话施压、装可怜、拿别人家孩子比较、威胁不再爱、贴标签。指出风险，给低风险的替代。与《育儿体系与话术的使用边界》一致。

## 三、给说法的规矩

做法层可以给成品句——一句可以直接照说的话，加上孩子可能的几种反应分别怎么接。这是这一层最主要的产出。《育儿体系与话术的使用边界》禁的是通用话术库和万能回复，不是具体说法。

给的时候守两条：一、说明条件与代价（按第二节的 B 级：什么时候谈、说几句、孩子不接受怎么办）；二、贴合使用者本人——用词、句长和家里的说话习惯，不要求他背句子。做法层是脚手架，不是剧本：照着他自己的话搭一次，下一次能自己搭。他要的是“这一次怎么开口”，不是一本话术库。

## 四、引用体系时的规矩

引用育儿体系时，区分有实证支持的方法、成熟框架和流行说法；除非使用者要求，不展开理论史或课程版本史。

## 五、主题指南

具体读哪一份，见 `SKILL.md` 的《按需加载》一节。两处常被直接问到：

- 判断“什么算一次好的沟通”（五维、卡点、等级）→ `references/knowledge/01-判断标准.md`。只用于有逐字材料的分析（录音转写、截图可见原文）；只有口述和回忆时不用这份，也不给分数与等级。
- 判断某个持续表现要不要建议求助 → `references/knowledge/06-孩子的表达方式与信号.md`

## 依据说明

本份是目录与使用说明，说明两层文件的组织方式、两套分级各自的含义，以及给说法时守的规矩。它不是知识整理，也不对应单篇研究——两套分级是本套材料自己定的规则，用途是让同一套判断在两层的不同文件里保持一致。

两套分级的设计依据是通行的证据分级思路。**证据分级**（机制层用）按来源强弱分 A/B/C/D 四档：A/B/C 是外部来源，按系统综述与元分析、单项研究、临床分类与流行框架排；**D 是外部没有对应来源、由本套材料自定的判据**，单列一档，不与 A/B/C 争强弱。**使用分级**（做法层用）分 A/B/C 三档，是使用门槛不是证据强弱：A 可直接给，B 要一并说明条件与代价，C 不给、只给替代。临床口径单独处理这一条，是把「要不要建议求助」和「怎么给沟通判断」分开，避免把诊断口径带进报告。

整体属证据分级 D（本套材料自定的规则）：本份定义的是本套材料内部的分级与写法规矩，不构成对孩子的测评或定性。各份内容的证据强弱，见各份自己的 `## 依据说明`。

## 参考文献

本份是目录与使用说明，两套分级（证据分级、使用分级）都是本套材料自定的规则，不对应单篇研究，也不指向任何一本育儿书，因此不列条目。

这里要说清楚一件容易被误读的事：本套材料引用育儿体系（依恋理论、非暴力沟通、正面管教、人本主义、个体心理学等）时，采用其含义而不逐条溯源，各份只在有明确落点时才列出对应的书。所以「某份没列书」不等于「这份没有依据」，也不是漏写——依据就是该份自己的 `## 依据说明`。
