# 关键流程

## 1. 首次使用与建档

**参与者**：使用者（长辈）、Agent  
**前置条件**：当前对话不存在档案，且事情不是正在发生  
**成功结果**：形成最小必要档案，并确定眼前问题

1. 使用者显式调用 Skill 或提出符合描述的亲子沟通问题。
2. **紧急例外**：事情正在发生、使用者情绪强烈或孩子提到伤害自己时，**先处理眼前问题，再补档案**，不机械展开问卷。
3. 发建档问卷，**只问六项**——孩子年龄与生理性别、你的年龄与关系、最近一个月关系怎么样、这次想从哪儿说起。**只有这份建档问卷用宿主自带的交互式提问能力呈现**（可点选的单选卡），分三组发出：孩子／你／眼下的处境。宿主单次题数有上限时把一组拆成两次；宿主没有这种能力时按同样顺序列出编号选项。**每项都可跳过**，也允许使用者直接讲故事、由 agent 提取。完整题目与选项见 `SKILL.md`《首次使用与紧急例外》。**建档之外的提问不用这套卡**——分析里的追问一律开放、由使用者自己输入，见第 5 节第 3 条。
4. **选「爸爸」「妈妈」不再问性别**（由关系直接得出）；选祖父母／其他亲属／老师时性别不明，**此时才补问性别**。
5. **其余信息第一屏一概不问**——学段、青春期状态、家里的做法、孩子平时的表达习惯等，**用到哪一项再单独问哪一项**，问的时候说清为什么需要它。**建档时最多补问两项，不占后面分析的追问额度**；从给出第一份分析起，一切提问都计入额度（第 5 节）。
6. 学段**由年龄换算**（五段见 `references/knowledge/02-学段差异.md`），不单独问；使用者自己报了学段就直接用，两者不一致时以年龄为准。
7. 关系自评问**描述档（五档），不问 0–10**——数字没有锚点，不同人填出来不可比。它只代表使用者当下的主观感受，**不当作测评结果、不擅自替人评分、不与任何常模比较**。
8. 收到回答后简短复述，只请使用者纠正关键误差。
9. 后续沿用已知信息，只补问会改变建议的变化。
10. 需要跨任务复用且尚未选择时，用一句话询问本地记忆同意；同意后才启用。

**隐私边界**：只需要结构字段，不需要孩子姓名、学校、生日、可识别照片或任何原话。问卷中的每项都允许留空。**写档案时的字段名以 `references/practical/10-长期记忆与亲子档案.md` 的清单为准**，不把题面文字直接当字段名（白名单会拒收）。

## 2. 有原话的逐句复盘（录音／聊天记录）

**前置条件**：拿到录音转写、聊天截图或导出记录  
**成功结果**：使用者看清转折点，并拿到可直接照说的说法

1. **转写**（录音时）：用 `scripts/transcribe.py`。脚本按环境变量选路——**有**腾讯云密钥就走云端（录音上传，给出说话人编号），**没有**就走本机 faster-whisper（离线、不上传）。产物是结构化逐字稿：时间戳、文字、由音频算出的音量与语速；本地路径另含把握度、非语音概率、重复度、解码温度，云端不返回这些。
2. **先讲清代价，再动手**：走云端时说明录音会上传并可能产生费用；走本机时说明大概要等多久（实测约 3.5–4.9 倍实时，1 小时录音约 15 分钟），**不说「马上好」**。
3. **角色确认（强制）**：本地转写不给说话人字段，角色只能按语言特征推断；云端给的编号也只是声学聚类，不是角色。按语言特征给出猜测，请使用者确认哪一句是自己说的、对不对；确认后才升级为事实。使用者分不清时，标注「角色为推测，可能有误」或建议重录，**不装作知道**。
4. **被切片时多一步**：录音超过单次 5MB 限额时会被切成几片分别识别（脚本自动压缩，尽量先试单次），此时**各片的说话人编号互不可比**。逐字稿里标了切片位置，须按对话内容确认跨片的是不是同一个人（看谁一直在回应谁），确认前不下结论。
5. 只把可确认的原文、说话人、顺序、间隔和表情写入事实；含义解释放入推测。
6. 长记录先显示并锁定「使用者／孩子」的说话人映射；优先使用 sender、member ID 或使用者确认，**不按左右、语气或性别猜**。
7. 进入五步分析（见第 4 节）。

**拒绝路径**：转写置信度低的片段单独标出，不基于不确定文本下结论。无密钥、无网络、云端失败或脚本不可用时，**如实说明失败原因，不伪造转写**，改为请使用者直接提供逐字稿。

## 3. 只有转述的复盘

**前置条件**：使用者只提供回忆和转述，没有原话  
**成功结果**：按事件顺序和反复出现的模式梳理，并明确标注依据性质

1. 开头先说明**依据是回忆、没有原话**。
2. 不做逐句证据，改按事件顺序和反复出现的模式梳理。
3. **不套 `references/knowledge/01-判断标准.md`**——它的维度、卡点判定和等级都要求逐句材料。不给维度分、不给卡点判定、不给等级；判断用描述性语言说，也不为凑一个精确数字去追问。
4. 只复述使用者讲到的事件和他自己的反应，**不做延展和假设**。

## 4. 每次分析（核心五步）

**成功结果**：使用者获得可解释、可执行、保留最终决定权的建议

1. **照见**：有原话时，用 2–4 句指出谁说了什么、在哪一句转折，并给原句位置；只有转述时只复述事件。使用者情绪高时先缩小到眼前这一个动作。
2. **事实拆分**：列原话能证明的、使用者转述的、合理推测的、仍然未知的。**首轮必须多列一项「基线未知」**——这件事他们平时是怎么做的，并让它优先占用首轮的追问额度。转写置信度低的片段单独标出。**不凭单次对话给孩子定性。**
3. **看见自己**：有逐字材料时读 `references/knowledge/01-判断标准.md` 后按维度给判断；只有口述和回忆时不读这份，改按事件顺序和模式给描述性判断。在「做得不好的地方」和「做得好的地方」上**分别给证据，两边都不省**。
4. **判断与建议**：有逐字材料时给分维度分数与总评等级；只有口述和回忆时不给分数、不给卡点判定、不给等级。再给一句首选和 2–3 条可以直接照说的句子，并说明孩子可能有哪几种反应、分别怎么接，**不写原则**。**首轮的「首选」必须是条件式**——基线未确认时写成「如果你们目前没有……那就……」，并讲明它建立在哪种前提上；基线确认后再收成直陈。中间轮只给增量判断，整体判断留到收束轮。
5. **本轮落点**：给一个现在能做的小动作、观察窗口或停止条件，以及值得回来反馈的具体信号。追问从全程**追问额度池**里扣（首轮 ≤2、之后每轮 ≤1、全程 ≤5），**首轮的额度优先给基线**（先问平时怎么做，再问细节）。**不告知使用者还剩几个**，额度用尽时也不通报。**追问一律开放提问、由使用者自己输入，不给可点选的选项**（见第 5 节第 3 条）。

**快捷路径**：使用者只问「这句怎么说」时，第一屏先给一条可以直接照说的成品，再写说的时机和孩子可能的反应。

## 5. 对话轮次与结束

**前置条件**：已进入一问一答的往复分析  
**成功结果**：分析在有限轮次内结束，并由 Agent 主动收尾

1. **一轮**＝一次「Agent 给出分析 → 使用者回应」的往返；建档案那一轮不计入。使用者只问一句「这句怎么说」的短问答**计入**——否则它会变成绕开上限的后门。
2. **上限**：分析轮目标 5 轮、硬顶 6 轮；追问全程 ≤ 5 个（首轮 ≤2、之后每轮 ≤1）。说话人角色确认、切片跨片是否同一人属前置校验，不占这 5 个额度。**使用者主动要求时可以突破**——「再问几个」「还能再问吗」这类话一出现，上限让位（它是保护使用者的，不是约束他的）：他指定了数量就按他说的来，**没指定数量时默认最多再追加 2 个**，用完就收。这个默认值是内部约束，**不告诉他，也不在任何一轮结尾报还剩几个**。
3. **怎么问：建档用卡，追问开放**。会弹可点选选项的**只有建档问卷**（第 1 节）。**分析里的一切追问都由使用者自己输入**——不预设选项、不写成「是 A 还是 B」让他挑、不替他猜几个可能答案。他打一句话、打三个字、或顺着自己的话讲开，都算回答；答案落在预想之外是正常的，不因为「不太对题」再补一个选项卡去收窄。追问措辞只从这次的真实对话里长出来，不用通用模板。
4. **用完就停，也不说**：额度用尽后直接转入收束，不再提问；**不向使用者通报配额**——不出现「问题问完了」「不能再问了」这类话，也不在每轮结尾报「还剩几个」。
5. **问不完就算了**：依据仍不足时，按手上材料给标着「依据有限」的判断，把没解决的部分写进「仍不确定」，**不靠追问补齐依据**。
6. **首轮先说清终点**：讲明这次大概几轮、最多几轮，让使用者知道有尽头；但**只讲轮数，不报问题个数**。
7. **各轮深度不同**：首轮完整走第 4 节；中间轮只给**增量**判断；收束轮宣布结束、给整体说明，**这一轮不再提问**。
8. **危机信号出现时上限失效**（自伤、被欺凌等），直接走第 7 节的安全流程，不受 5／6 约束。
9. **收束轮**（由 Agent 主动开始，不等使用者说「就这样吧」）：
   - **明确宣布结束**——说的是「我不再提问了」，是承诺而非暂时不问；
   - **给整体说明**替换掉增量分析：完整链条／你做对的地方（附证据）／要改的只留 1–2 条／下次直接说的话／仍不确定的部分／观察窗口。
   - 只有口述和回忆时（第 3 节），收束说明用描述性语言，**不给维度分、不给卡点判定、不给等级**；维度分与等级只属于有逐字材料的素材分析路径（第 2 节）。

## 6. 主题路由

**前置条件**：已确定本次场景  
**成功结果**：只加载 1–3 份必要参考，不批量载入全库

1. 按使用者的说法判断落在哪一类主题。
2. 先读这一类对应的**机制文件**（`references/knowledge/`）。
3. 要动手时再读对应的**操作文件**（`references/practical/`）。
4. 风险或证据争议出现时，优先补读 `references/knowledge/08-危机识别与求助渠道.md`。
5. 需要其他主题时先读 `references/00-导读与使用分级.md`。
6. 使用者想换用别的云端、更强的模型或 MCP 转写工具时，读 `references/转写升级路径.md`。

## 7. 安全信号（E）

**前置条件**：录音或记录中出现红线内容  
**成功结果**：先保安全、再谈沟通；使用者仍可自行决定是否继续看分析

1. **暂停常规报告**——这一轮记为 E，不写等级、不给沟通评价。
2. 说明这次已超出沟通分析范围，只做一件事：把渠道给出去。
3. 给渠道，并说清哪一条对应现在的处境（12356／12355／12338／12348／12309／110／120）。
4. **最后才问**：这次的分析还要不要看。
5. **不跳过第 4 步自行决定不给**——看与不看，使用者自己定。

**红线期间的特殊规则**：不复述敏感原句、不追问细节、不诊断、不承诺做不到的陪伴、不说「这不算什么」。

## 8. 长期记忆更新与控制

**前置条件**：已获得首次明确同意  
**成功结果**：跨任务保留有限结构，且随时可查、可停、可撤、可删

1. 每轮只提取会改变未来建议的少量变化；重复内容更新原字段，不追加副本。
2. 只写白名单字段（见 [变量与配置](variables.md)）；字段名里出现黑名单词一律拒绝。
3. 成功更新后显示一句摘要与撤销方式；失败时说明**未持久化**，不显示「记忆更新」成功提示。
4. 使用者可随时查看、暂停、恢复、撤销、忘记某一对象、撤回同意或清空全部。
5. 达到条数上限时合并或删除低价值条目，**不扩容**。

## 9. 长辈情绪很激烈

1. 先缩小时间范围，避免当场再起新一轮冲突。
2. 先分清是「想错了」还是「撑不住了」，给当天能做的动作。
3. 判断重点在家长自己的耗损，不把责任推回孩子身上。
4. 若涉及家长自身的安全风险，转入安全流程。

## 10. 需要转专业的情形

1. 识别是否存在医学问题（发育异常、性健康、持续的情绪与行为变化）。
2. 不在本 Skill 内做诊断；说明局限并建议就医或专业帮助。
3. 涉及法律定性时，只说明方向，建议咨询律师或办案机关。
4. 每份报告末尾固定一行：**这不是诊断，也不替代专业帮助。**
