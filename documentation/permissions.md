# 权限边界

## 运行角色

| 角色 | 能力 | 不能做什么 |
| --- | --- | --- |
| 使用者（长辈／老师／亲属） | 提供信息、上传录音或记录、决定是否采用建议、决定是否启用长期记忆、决定是否启用云端转写 | 不通过本 Skill 自动获得他人的账号、位置或私密数据 |
| Agent | 读取 Skill 与按需参考；调用转写脚本处理录音（默认本机离线）；使用者同意后调用本地记忆脚本 | 不自动发送消息、不读取聊天软件数据库、不绕过宿主工具批准、不代使用者申请或填写云端凭据 |
| 未成年人（对话对象） | 是分析的对象，不是使用者 | **不被测评、不被评分、不被贴标签、不被加任何字段** |
| 仓库维护者 | 修改公开文件、审查贡献和发布版本 | 无权访问使用者在本地任务中的内容 |
| 贡献者 | 通过 Issue 或 PR 提交公开内容 | 不应提交可识别的真实家庭案例或未经授权的私密材料 |

## 资源与操作矩阵

| 资源 | 使用者 | Agent | 维护者／贡献者 |
| --- | --- | --- | --- |
| `SKILL.md` 与参考资料 | 可读取 | 可读取 | 通过版本控制修改公开副本 |
| 当前任务对话 | 可提供和查看 | 仅按宿主上下文访问 | 默认不可访问 |
| 录音文件 | 提供并授权处理；决定走本机还是云端 | **默认仅在本机转写，不上传、不留存**；使用者自行配置腾讯云密钥后会走云端并上传处理 | 不可访问 |
| 转写中间文件（编码切片、试编码） | 无需关心 | 落在输出目录，用后即删；失败退出路径同样清理 | 不可访问 |
| 云端凭据（腾讯云密钥） | **自己申请、自己填进环境变量** | 只从环境变量读取，**不写入任何文件、日志或 Skill 目录** | 不可访问 |
| 聊天截图／导出记录 | 提供 | 只读可见原文，不补线下信息 | 不可访问 |
| 用户本地文件 | 按宿主授权 | 仅在宿主提供工具且用户授权时访问 | 不可访问 |
| 本地受限记忆 | 可同意、查看、暂停、撤销、删除、清空 | 仅按同意状态和脚本门禁读写 | 默认不可访问，绝不进入仓库 |
| 外部消息或账号 | 自行操作 | 本 Skill 不要求任何写权限 | 不可访问 |

## 使用者身份的权限差异

| 使用者身份 | 额外要求 | 能做什么 |
| --- | --- | --- |
| 父母／监护人 | 无 | 完整流程 |
| 祖父母、其他亲属 | 无（但建议涉及法律边界时提示监护人） | 完整流程 |
| **老师、非监护人亲属** | **上传录音或记录前，必须先提示需取得孩子监护人的同意**；启用云端转写前同样要提示——那意味着录音离开本机 | 可以分析，但报告口径按教育场景调整 |
| 录音中涉及他人家的孩子 | **先提示同意与用途的正当性** | 不替使用者判断合法性 |
| 启用云端转写 | 使用者自己决定并自行配置密钥 | 录音会上传到腾讯云处理；使用者可用 `--provider local` 随时改回不上传 |

## 数据与权限实现

仓库本身没有用户数据库、令牌、角色声明或行级安全机制。`scripts/memory_store.py` 只在使用者首次明确同意后于本地用户数据目录创建限量 SQLite 文件，并使用来源、条数、白名单和撤销校验；它不提供跨操作系统账号隔离。

默认路径（可用环境变量覆盖，见 [变量与配置](variables.md)）：

- Windows：`%LOCALAPPDATA%\manmantalk\`
- 其他：`$XDG_DATA_HOME/manmantalk/` 或 `~/.local/share/manmantalk/`

写入前有三道门：

1. **同意状态门**：未 `enable --confirm` 拒绝写入。
2. **字段门**：只接受白名单字段；字段名里出现黑名单词（原话、逐字稿、录音、姓名、学校、班级、生日、地址、电话、手机号、身份证、诊断等）直接拒绝。
3. **条数与长度门**：每个作用域有上限，单值 200 字符，达到上限时合并或删除而非扩容。

云端转写不改变上述三道门：它只影响「录音在哪被转成文字」，转写产物仍落在使用者指定的输出目录，不会进入记忆库，也仍然受黑名单约束（逐字稿不进档案）。
