# 知识库治理

## 分层

| 层级 | 目录 | 用途 |
| --- | --- | --- |
| 行为规则 | `SKILL.md` | 决定何时询问、怎样分析、怎样输出、何时切换安全流程 |
| 导读 | `references/00-导读与使用分级.md` | 两套分级（证据分级、使用分级）与使用说明 |
| 机制层 | `references/knowledge/` | 为什么会这样、怎么判断、边界在哪 |
| 做法层 | `references/practical/` | 这一步该怎么做、这句话怎么说 |
| 专项 | `references/knowledge/08-危机识别与求助渠道.md`、`references/practical/10-长期记忆与亲子档案.md` | 危机转介、长期档案；均不参与常规报告的判断主路径 |

加载顺序固定为**先机制、后做法**。默认只读当前问题直接需要的 1–3 份，不批量加载整套参考。

## 两套分级

### 证据分级（A–D）

| 级别 | 依据类型 | 可以怎么表述 |
| --- | --- | --- |
| A | 系统综述、元分析、大样本纵向研究、**现行法律与权威指南** | 「证据较一致」「现行规定为」 |
| B | 设计良好的单项研究、多个团队反复出现的发展规律 | 「有研究提示」「可能如此，仍需结合情境」 |
| C | 临床分类、流行框架、经验说法 | 「一种常见说法」「可作为参照」 |
| D | 本套材料自定的判据与规则，外部没有对应来源可挂 | 「本套材料的做法是」 |

每条实质结论必须能挂到对应级别。A/B/C 是外部来源强弱，D 是外部没有对应来源、由本套材料自定的判据，**单列一档**——它的用途是**让使用者知道这句话有多硬**，不是给内容排序，也不读成「比 C 更弱」或「没有依据」。

### 使用分级

做法层给做法时，按使用门槛分 A/B/C 三档——**这不是证据强弱，是给不给、怎么给的界限**：A 可直接给（说事实不说判断、先接情绪再谈事等），B 要看条件（给的时候一并说明适用条件、预期效果与代价），C 不给（撤回关注、制造愧疚、贴标签等，只给低风险替代）。

做法层按学段给倾向，不按年龄精确切分。原因是同一个表现在不同学段是不同的事，且个体的发育差异远大于年龄差。判据在 `references/knowledge/02-学段差异.md`。

学段这条线在机制层有**两个入口，分别管两侧**：`references/knowledge/02-学段差异.md` 讲**孩子那一侧**（这一段的孩子是怎么回事、表现的含义为什么不同）；`references/knowledge/04-家庭系统与教养方式.md` 第七节讲**长辈那一侧**（同一个教养动作在各学段该长什么样）。两者互为反向指针，不重复内容——**判断孩子看 `02`，调整自己看 `04`**。

## 依据与正文的绑定规则（硬约束）

这是本项目最容易出问题、也最被强调的一条：

1. **每一条列出的依据，正文必须有角标落点。** 编号体系：
   - 论文／研究报告：［1］［2］…（半角方括号）
   - 书籍：［B1］［B2］…
   - 法律条文：［L1］［L2］…
2. **禁止「链接与依据不匹配」。** 不把通用育儿理念挂到法条或机构文件位置上，也不为了凑数给某份硬挂一本书。
3. **依据本就是非学术文件时，明确写「不列论文、不列书籍」**，并说明理由（如 `references/knowledge/07-法律与权利边界.md` 依据是法条、`references/knowledge/08-危机识别与求助渠道.md` 依据是机构文件、`references/practical/10-长期记忆与亲子档案.md` 是工程与合规设计）。**「不列」不等于「没有依据」**，也必须在文件里说清这一点，避免读者误读。
4. **跨份重复上限**：同一论文／书在机制层内出现不超过 2 次；做法层引用机制层的论文不计入上限。
5. **书籍准入标准**（二选一）：总销量高的畅销书，或作者是业内泰斗级人物。
6. **不做无依据主张。** 输出不做没有落点的断言；查不到、判不了就写未知，不猜。

## 引用育儿体系的方式

本套材料引用依恋理论、非暴力沟通、正面管教、人本主义、个体心理学等体系时，**采用其含义而不逐条溯源**。各份只在有明确落点时才列出对应的书。

`references/knowledge/01-判断标准.md` 属特例：五维度、卡点清单、五档等级和折算规则**都是本 Skill 自己定的判据**（证据分级 D），作用是统一口径，让同一段对话在不同时候得到同一套判断。它**只用于有逐字材料的分析**（录音转写、聊天截图的可见原文）；只有使用者的口述和回忆时整份不用，也不给维度分与等级。它参照了八个体系的框架含义，但不把判断挂靠学术出处。

## 未成年人的特殊约束

- 不对未成年人做任何测评或评估，不给未成年人贴任何人格标签。
- 孩子侧只做**观察记录**，用途是印证家长的做法是否起了作用，不是评价孩子。
- 五档等级（S/A/B/C/D）评的是**这次沟通的质量**，不是孩子；只出现在有录音或截图的素材分析报告里。
- E 是安全红线代号，不在五档轴上，不与它们比高低。

## 更新规则

- 法律、求助渠道、政策信息引用前复核日期与地区，并在文件中标注核实时间。
- 新增研究时优先补充原始或权威来源，不只添加二手总结。
- 修改做法时保留「适用场景—孩子可能反应—怎么接—代价／停止条件」结构。
- 新增文件时同步更新 `SKILL.md` 路由表、`references/00-导读与使用分级.md` 与 `README.md` 目录结构。
- 删除内容时检查 `SKILL.md` 路由和所有相对链接。
- **不把真实用户或真实孩子的案例直接沉淀进公开知识库。**
- 不以篇数或字数作为质量激励，不为凑数扩写。

## 核心原则（判断冲突时的优先级）

当「对使用者最有利」的几种理解发生冲突时，按此顺序：

1. **孩子的长期安全感与表达意愿**
2. 使用者的可信度（家长说的话算不算数）
3. 亲子关系的长期修复能力
4. 使用者自己的情绪耗损

即：**不要把孩子听话当作唯一胜利。**
