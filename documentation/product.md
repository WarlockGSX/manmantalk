# 产品定位

## 产品主张

慢慢Talk 不是替家长教育孩子的「育儿教官」，也不是话术库。它是一个**亲子沟通教练**：先把刚才那段对话里谁说了什么、在哪一句发生转折照出来，再把事实、推测和未知拆开，然后给出下次可以直接照说的句子，连孩子可能有哪几种反应、分别怎么接一起给。

它的立场有一条明确的偏好：**更倾向站在孩子一边**。但这份倾向只体现在「如何解释事实」——优先考虑孩子当时的处境，不体现在替孩子判家长对错。给判断，但不读心。

## 核心用户与价值表达

| 用户 | 典型困境 | 价值表达 |
| --- | --- | --- |
| 刚吵完架的家长 | 心里过不去，反复回想哪句话说错了 | 逐句复盘转折点，做得不好的地方和做得好的地方都给证据 |
| 不知道怎么开口的家长 | 想聊成绩、手机、早恋、性教育，一开口就变成说教 | 先给一条可以直接照说的成品，再给时机与几种接法 |
| 规则执行不下去的家长 | 作业、手机、睡觉的约定定了，孩子不配合 | 先分清是哪一种失败（没参与约定／约定不合理／执行走样），再给切分做法 |
| 面对沉默与回避的家长 | 孩子不说、敷衍、关门 | 先分清是暂时不想说还是长期不说，分别给做法 |
| 家庭有变故的家长 | 离异、单亲、丧亲、重组，不知道怎么跟孩子讲 | 按顺序说，把大人的事和孩子的事分开 |
| 老师与非监护人亲属 | 想帮忙，但身份和权限都不清楚 | 明确提示需先取得监护人同意，并划定能做什么、不能做什么 |
| 需要复盘录音的用户 | 有录音或逐字稿，想看清自己当时的表达 | 默认本机转写 → 角色确认 → 逐句分析；使用者自己配置云端密钥后可改走云端，拿到说话人编号（仍是声学聚类，不是角色）。不还原说话人身份，也不把音量、语速这类物理量当作心理状态的证据 |
| 想跨次追踪变化的用户 | 每次都要重复交代背景 | 首次明确同意后，跨任务记住有限的结构字段；可随时查看、暂停、撤销、删除 |

## 差异化能力

1. **先照见，再给方法**：不是先给结论。有原话时先指出谁在哪一句转折，方法放在后半段。
2. **两边都给证据**：在「做得不好的地方」和「做得好的地方」上分别找证据，不为了批评而批评，也不为了安慰而省略。
3. **原句证据优先**：有录音转写或聊天记录时引原句并给位置；只有转述时，明确标注依据是回忆，不还原没被讲到的对话，也**不套五维度、卡点与等级**（那需要逐句材料）。
4. **说话人角色必须确认**：本地转写不含说话人字段，角色只能按语言特征推断；云端给的编号也只是声学聚类，而且长录音被切片时，编号还只在片内可比。两种情况都必须由使用者确认，确认前不下任何结论。
5. **学段校准**：同一个表现在不同学段是不同的事。不凭一次表现定轻重，不先归到性格上。
6. **只给可执行的说法**：拒绝「你应该多共情」这类空话；给的是能直接照说的句子，并连同孩子可能的反应和分别怎么接。
7. **报告是镜像，不是成绩单**：给等级和维度分是为了让家长看清这次谈得怎么样，不给孩子打分、不给孩子测评、不给孩子贴标签。等级与维度分只出现在有录音或截图的素材分析里；靠口述和回忆时用描述性语言说，不给分数。
8. **E 安全红线独立于质量档**：出现自伤、被欺凌、被不当触碰、动手致伤等信号时记为 E，暂停常规报告，先给求助渠道；E 不与 S/A/B/C/D 比高低。
9. **同意后受限记忆**：默认不开启；同意后只写结构字段，字段名里出现原话／姓名／学校等词会被直接拒绝。
10. **默认转写不上传**：录音默认在本机离线转写，不离开这台机器。只有使用者**自己**配置腾讯云密钥后才会走云端，包内不含任何凭据；随时可用 `--provider local` 关掉。转写产物不进报告正文。
11. **分析有终点**：分析轮目标 5 轮、硬顶 6 轮，追问全程不超过 5 个（首轮最多 2 个、之后每轮最多 1 个）。到点由 Skill 主动收束并给一份整体说明，不无限追问；配额用尽后静默转入收束，**不向使用者通报剩余额度**；出现危机信号时这个上限自动失效；**使用者主动要求时可以突破**（「再问几个」——他指定数量就按他说的来，没指定时默认再追加 2 个，这个默认值同样不告知）。**追问一律开放提问、由使用者自己输入**——只有建档问卷是点选，追问不预设选项、不替使用者猜答案。

## 非目标

- **不替家长教育孩子。** 方法只用于看清这次发生了什么，不构成让孩子服从的手段。
- **不提供通用话术库与万能回复。** 每一次的说法都要从这一次的真实对话里长出来，换场合不一定还能用。
- **不对未成年人做任何测评、评估或贴标签。** 孩子侧只做观察记录，用途是印证家长的做法是否起了作用。
- **不诊断心理疾病。** 长辈自评只作为使用者自己的参照，不与常模比较、不与诊断标准挂钩。
- **不替代专业帮助。** 遇危机转介，不承诺陪伴。
- **不提供法律意见。** 只说明「这件事有没有明确的法律规定、方向是什么」，个案定性留给律师或办案机关。
- **不用于任何商业目的。** 见 `LICENSE`（PolyForm Noncommercial 1.0.0）。
- **不默认上传数据。** 默认不需要账号或密钥，记忆存本机用户目录。唯一的外部传输是使用者自行启用的云端转写。本包也不内置账号申请、密钥托管或用量计费——那是使用者自己的事。

## 产品成功信号

当前项目没有遥测。评估应使用匿名或合成案例，关注：

- 有原话时，是否给出可定位的转折点，而不是笼统评价。
- 「做得不好」和「做得好」两边是否都给了证据，没有一边被省掉。
- 说话人角色未确认时，是否拒绝下结论。
- 只有转述时，是否明确标注依据是回忆、不虚构对话，且未套用维度分与等级。
- 给出的说法是否可以直接照说，而不是原则性建议。
- 是否给出了孩子可能的几种反应及各自的接法。
- 孩子侧是否始终没有被评分、被测评、被贴标签。
- 出现安全信号时，是否正确切换为「先给渠道、再问是否继续」的顺序，且未复述敏感原句。
- 长期记忆是否在首次明确同意后才启用、只写白名单字段、每次提示撤销。
- 报告是否避开了让孩子服从的表达（撤回关注、制造愧疚、反话施压、装可怜、比较别人家孩子、威胁不再爱）。

## 路线图

- 建立匿名合成案例评测集，覆盖日常冲突、沉默回避、敏感话题、家庭变故、校园处境与危机六类场景。
- 为 `references/` 每份补充「核实时间」元数据，便于判断时效。
- 为长期记忆增加可视化审阅界面；当前版本使用本地命令查看、撤销和删除。
- 评估是否需要按地域细化求助渠道（如地方心理援助热线、地方妇联）。
- 家庭变故与成长命题（性教育、爱、死亡、恋爱、价值意义、单亲／离异／丧亲）两类内容继续扩充。
- **说话人身份跨切片对齐**：云端转写因单次 5MB 限额被切片时，各片的说话人编号互不可比，目前只能靠使用者按对话内容确认。评估能否自动对齐，减少这一步手工确认。

## 与其他包的关系

本包是 `goutoujunshi`（狗头军师／恋爱场景）经过场景迁移与专业化后的产物。两者共用「依据说明 + 参考文献 + 两层 references（knowledge／practical）」的知识组织方式，但**领域、字段、判据与安全边界完全不同**，不共享任何运行时文件。
